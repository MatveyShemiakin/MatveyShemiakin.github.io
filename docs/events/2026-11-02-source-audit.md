# Worldwide catalogue source audit — 2 November 2026

Scope: all 98 input records in PR #80, plus a search of official society calendars for Russia/CIS, Europe, Greater China, Asia-Pacific, Middle East, Africa, North America, Latin America and online meetings. Dates are not inferred from previous editions. This is a curated catalogue, not a claim to enumerate every meeting worldwide.

Result: 107 unique meetings; 12 additions; 3 duplicate records consolidated. Historical meetings remain available with the past-events filter.

## Method and limits

Organiser/event pages and official society calendars were retrieved on 2 November. Direct-fetch failures were checked against indexed official pages; an HTTP success alone was not treated as factual verification. Sources with conflicting fields have a note below; unsupported deadlines, hours, or open-submission claims were removed. Individual acceptance-email deadlines are not published as general congress deadlines.

## Confirmed deadlines

## Unresolved organiser inconsistencies

- MIOC: standard registration cutoff differs between the dates page (20 November) and fee table (25 November); no single cutoff is advertised. Early-bird cutoff 15 November agrees.
- WSOPRAS: abstract cutoff 14 December and video-file cutoff 30 November are both retained and explained; conflicting notification dates are omitted.
- EURETINA/SOE/EPOMEC pages contain stale template text; only clearly labelled current-year fields were retained.
- AAO main website and COS pages return 403 to direct automated fetches; official indexed content and society calendars confirm dates. CCOS origin returned 521.
- Cloud browser fails initialization; local Chromium cannot create its process socket in this environment. Browser checks must run in CI. Physical Android/iOS/Safari testing is not available here.

## Monitoring and interface review

All 40 retained deadline URLs have dedicated source monitoring with current date context; prior valid contextual terms are retained. A calendar-day opening date is never converted to an invented noon cutoff. Catalogue coordinates feed the globe directly, so adding a meeting no longer requires an ID-specific JS coordinate change. The desktop events hero clears the homepage minimum height.
