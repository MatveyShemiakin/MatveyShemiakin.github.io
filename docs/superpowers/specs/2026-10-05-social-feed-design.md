# Публикации из соцсетей — схема подключения
Дата: 2026-10-05

## Цель
На matveyshemyakin.ru появляется раздел «Публикации из соцсетей» по адресам /social/ (RU) и /en/social/ (EN). Источники: канал https://t.me/DrShemMYu и Instagram https://www.instagram.com/dr.shemyakin/.
Карточки содержат текст, дату, название источника, ссылку на оригинал и доступную обложку. Текст формируется в статическом HTML. Существующее оформление и функции сайта сохраняются.

## Проверенное состояние
Репозиторий MatveyShemiakin/MatveyShemiakin.github.io, основная ветка main, домен подтверждён CNAME.
Пользователь сообщил о сохранении TELEGRAM_BOT_TOKEN в GitHub Actions.
В репозитории уже есть publish-doctors-updates-telegram.yml: он отправляет обновления сайта в канал, используя тот же секрет. Не запускать его вручную и не менять его в рамках импорта.
Бот: @DrShemMYubot. Членство и права в канале необходимо проверить через Bot API в Actions без вывода токена.

## Telegram: первый этап
Отдельный workflow получает channel_post и edited_channel_post через getUpdates. Перед первым импортом проверяет getMe, членство в целевом канале и getWebhookInfo.
Если webhook уже установлен, завершает работу с безопасной диагностикой: не удаляет и не заменяет его.
Принимает сообщения только из канала с username DrShemMYu; игнорирует личные сообщения и другие каналы.
Уникальный ключ записи — идентификатор канала и message_id. Редактирование заменяет существующую запись. Альбомы объединяются по media_group_id.
Сохраняет нормализованные публичные записи и offset в репозитории. Offset подтверждается только после успешного сохранения данных. Запуски сериализованы.
Telegram хранит необработанные обновления не дольше 24 часов. Суточный getUpdates на GitHub Actions не гарантирует полноту при задержке или пропуске запуска. До реализации выбрать надёжный приём webhook с буфером и ежедневной сборкой либо явно согласовать ограничение суточного polling. Не обещать гарантированный импорт при суточном polling.
Бот API не предоставляет историю канала: импортируется доступная очередь и последующие посты. Автоматического получения уведомлений об удалении поста нет; предусмотреть список исключённых записей.
Текст и ссылки экранируются, внешние ссылки допускают только https/http. Обложки загружаются только через проверенный Telegram file endpoint, с ограничением размера; видеозаписи не копируются целиком.
При сбое API ранее опубликованная лента сохраняется. Секрет не попадает в HTML, JSON, git, артефакты или логи.

## Сборка и публикация
Первый запуск — диагностический и ручной. Затем workflow по расписанию, один раз в сутки для обоих источников (GitHub может задерживать запуск).
Изменения сначала готовятся в отдельной ветке. В main попадают после проверок.
Workflow с GITHUB_TOKEN, который коммитит HTML, сам по себе может не запускать существующий деплой. Перед включением расписания проверить текущий механизм хостинга и выбрать подтверждённый способ обновления сайта; не менять платформу хостинга.
Навигация получает ссылку на /social/, sitemap — новую страницу. Обе языковые версии используют текущие стили, шрифты, цвета, переключение темы и компоненты навигации сайта. Обязательна адаптация для мобильного и настольного экрана. Интерфейс RU — «Публикации из соцсетей», EN — «Social media posts». Подписи постов сохраняют исходный язык; автоматический перевод медицинского текста не включён.
Пустое состояние честно сообщает, что публикации ещё не импортированы, и предлагает открывать канал/профиль.

## Instagram: второй этап
Не показывать Instagram как подключённый до успешной авторизации официального API.
Проверить тип аккаунта и актуальный официальный процесс Meta. Потребуются приложение/авторизация и безопасные секреты.
Общий формат данных и карточек заранее поддерживает Instagram. Отсутствие его доступа не мешает Telegram.
Сбор пароля или неофициальный scraping не предусматриваются.

## Проверки
Тесты фильтра канала, повторного импорта, редактирования, альбомов, HTML-экранирования, неуспешного API и сохранения offset.
Диагностический Actions запуск без раскрытия токена.
Один новый пост из канала должен появиться в ленте, редактирование — обновить ту же карточку.
Проверить мобильную и настольную страницу, навигацию, sitemap, отсутствие ошибок и существующие функции сайта.
Отдельно подтвердить получение новой версии страницы на публичном домене.

## Критерии завершения
Telegram подключён только после успешного живого теста получения поста и публикации HTML.
Instagram остаётся обозначенным как неподключённый до успешного живого теста.
